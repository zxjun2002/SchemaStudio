#SchemaStudio

因为配置表侧定制化需求较多，因此生成时候的数据直接放在配置表里面会很占位置，因此生成时候配置单独用json存储，该工具就是用于对json进行快速操作

> 配套生成工具：
> [ConfGenTool（Gitee）](https://gitee.com/zxjun2002/conf-gen-tool)

---

## ✨ 特性

- **支持多种格式**：支持 `.csv / .xlsx / .xls`（可选多 Sheet）。
- **自定义用户属性**：可以根据比如客户端表和服务端表等自定义用户数据。

## 配置工作台

界面采用资源树、多标签编辑区、右侧字段属性和底部问题列表。支持直接编辑数据、Excel/CSV 复制粘贴、撤销重做、追加行列，以及数据/结构/JSON 预览切换。数据与 `.schema.json` 共用编辑状态；同一工作簿的多个 Sheet 共用一个文档，保存时一起提交。

属性库支持 `enum / bool / int / string`，范围为 `column / table / both`。客户端、服务端、多语言等都通过属性库定义，字段属性保存在已有 JSON 协议中。修改列名会保留该列的类型、主键与自定义属性。**类型必填，自定义属性可选**：新增列时先选择类型，可按需勾选属性；外部新增的列在列头、右侧面板及校验列表中提示“类型待配置”。检测到的数据类型只是建议，选择类型或点击“确认字段类型”后才写入配置，已有属性会保留。

### 文件与公式

| 格式 | 编辑与保存行为 |
| --- | --- |
| CSV | 编辑文本、追加或删除行列；保留编码、分隔符、换行风格及字段中的空格、前导零。以 `=` 开头的内容也是文本。 |
| XLSX | 编辑普通单元格、修改普通表头、在末尾追加行列。保存时局部更新原工作簿中的单元格，保留其他 Sheet、样式、链接及扩展部件。 |
| XLS | 查看数据与配置字段属性；为避免旧格式重写损失，数据只读。请先用 Excel 另存为 XLSX。 |

所有公式、共享公式、数组公式、外部引用、结构化引用、合并区域和受保护工作表都禁止修改，没有解除公式保护的入口。表格显示公式的**上次保存结果**，选中受保护单元格时上方显示“已锁定”和圆圈问号，点击可查看原因与公式表达式。无缓存时明确显示“无缓存结果”，不会把公式文本当作计算结果。本工具不计算公式，也不更新外部工作簿链接；修改数据后，需要在 Excel / WPS 中重算并保存，再点击“重新加载”并运行配套生成器，避免使用旧的公式缓存。“外部打开”使用系统默认的表格程序打开源文件。

XLSX 不提供删除或移动已有行列，因为这些操作涉及公式、名称、结构化表及外部引用的迁移。Excel 结构化表的表头和结构也由 Excel 维护。第 1 行有空字段名或重复字段名的辅助 Sheet 只供查看，不会自动生成一份错误的字段配置。

只修改字段属性时，原始表文件不会重写。保存前会检查原文件与配置 JSON 是否被外部修改；发生冲突会拒绝覆盖。替换前的文件备份在原目录的 `.schemastudio-backups` 中。一次保存未能完成时会尝试恢复本次写入，并保留内存中的修改。

### 运行与检查

需要 Windows 与 .NET 8 SDK。界面使用现有 WinForms 控件统一绘制，没有新增商业组件或在线服务依赖。

```powershell
dotnet run --project SchemaStudio/SchemaStudio -- Examples
```

也可以传入单个 CSV/XLSX 文件路径，或者把文件拖进窗口。快捷键：`Ctrl+O` 打开、`Ctrl+S` 保存、`Ctrl+Shift+S` 全部保存、`Ctrl+Z / Ctrl+Y` 撤销重做、`Ctrl+W` 关闭标签、`F5` 校验。

独立检查程序验证 CSV 往返读写、公式/链接保护、字段配置、撤销、外部修改冲突、保存失败恢复等，不改动用户数据：

```powershell
dotnet run --project SchemaStudio/SchemaStudio.Checks
dotnet run --project SchemaStudio/SchemaStudio.Checks -- --ui
```

`--ui` 会在屏幕外创建测试窗口，检查实际编辑与布局，并在 `artifacts/checks/studio-preview.png` 生成截图。校验基于当前未保存的数据，包含类型与主键检查；公式结果需在 Excel 中另行重算与校验。
